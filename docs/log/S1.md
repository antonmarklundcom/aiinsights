# S1 — Dashboard filters, pagination, components

## Built
- Category filter (`?category=`, enum from `src/db/schema.ts`) and tag filter (`?tag=`,
  jsonb containment via `sql`), both server-side URL params.
- Cursor pagination on `(created_at, id)`: 50 per page, "Load more" link appends
  `?before=<createdAt>_<id>`; the old hard `limit(100)` is gone.
- `src/components/`: `ItemCard`, `FilterBar`, `TagLink`, `CopyMarkdownButton` (the one
  client component), plus small helpers `category-label.ts`, `relative-time.ts`,
  `query-string.ts`.
- Cards: category pill, up to 4 clickable tags, relative saved time, an
  "attempt N/3 · failed" or "needs note" badge in place of the plain status pill for
  those two states.
- Detail page: `ai_model`/token-count muted line, "Copy as Markdown" button (title, url,
  summary, steps), tags are links, re-run button reads "Re-run summary (forces past 3
  attempts)".
- `globals.css`: `body` now uses `var(--font-sans)` (Geist) instead of the Arial override.
- Deleted the five unused `public/*.svg` leftovers from `create-next-app`.

## Decisions
- Card is a "stretched link" (`<Link className="absolute inset-0">` inside a `relative
  <li>`) rather than wrapping the whole card in one `<a>`, so the per-tag `TagLink`s can
  sit above it (`relative z-10`) and take their own click without nesting `<a>` in `<a>`.
- Tag filter uses `sql\`${items.tags} @> ${JSON.stringify([tag])}::jsonb\`` (jsonb
  containment) rather than a Drizzle array helper — `tags` is `jsonb`, not a pg array.
- `category` param is validated against `ITEM_CATEGORIES` before it reaches the query;
  an unrecognized value is silently ignored rather than sent to `eq()`.
- Cursor is the opaque string `<createdAt ISO>_<id>`, decoded only in `page.tsx`; the
  row-wise compare `(created_at, id) < (cursor.createdAt, cursor.id)` matches the
  `orderBy(desc(createdAt), desc(id))` tie-break.
- `q` search kept exactly as the ILIKE implementation it already was — S4 replaces it.

## Known issues
- Tag matching is exact and case-sensitive (jsonb containment); no normalization layer
  exists yet. Fine while tags are Claude-generated and lowercase by convention.
- No `loading.tsx` for `/` or `/items/[id]`; both are already `force-dynamic` from the
  session cookie read in the root layout (O3), so this is a pre-existing gap, not new.
- Screenshots were taken against a local Postgres 16 + a temporary `drizzle-orm/node-postgres`
  swap of `src/db/index.ts` (Neon's HTTP driver can't reach a plain TCP Postgres); the
  swap and the `pg` package were never committed — `src/db/index.ts` is back to the
  Neon driver on this branch.
